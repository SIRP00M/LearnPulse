# Mobile build and signing

See [root setup](../README.md). Dart/Flutter source, ARB/generated localization files, tests, Android settings and wrapper are included. Localization Dart files are generated by `flutter gen-l10n` and retained so imports resolve before regeneration.

Release signing requires `android/app/key.properties` with `storeFile`, `storePassword`, `keyAlias`, `keyPassword`. Keep the keystore outside this repository; obtain it securely from the Owner. Paths are absolute or relative to `android/app`. Signing files and local SDK paths are excluded. The build validates release signing and never substitutes a debug key.

`flutter build apk --release --dart-define-from-file=defines.local.json` is only appropriate after signing configuration and release authorization. No signed release was produced for this source package.
